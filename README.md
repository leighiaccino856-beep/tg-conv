# tg-conv — бот-конвертер видео в кружки Telegram

Бот на **aiogram 3** + **ffmpeg**: принимает видео (или GIF, или готовый кружок)
и возвращает **видеосообщение (кружок)** — квадратное MP4 с H.264/AAC.

## Что умеет

- принимает видео, видеофайлы-документы, GIF-анимации и кружки;
- работает по ответу на сообщение: ответь на чужое видео — возьмёт его;
- обрезает кадр по центру до квадрата и уменьшает до 640×640;
- обрезает длину до 60 секунд;
- **сам подбирает битрейт под целевой размер** двухпроходным кодированием,
  а если Telegram всё равно отказался принять файл — пережимает сильнее (до 1 МБ);
- показывает прогресс конвертации и чистит временные файлы;
- ограничивает число одновременных конвертаций (чтобы не положить сервер).

## Требования

- Python 3.10+
- ffmpeg и ffprobe в `PATH` (или пакет `imageio-ffmpeg` — см. ниже)
- токен бота от [@BotFather](https://t.me/BotFather)

Проверить ffmpeg:

```bash
ffmpeg -version
ffprobe -version
```

## Быстрый старт

```bash
cd E:\code\tg-conv

python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate

pip install -r requirements.txt

copy .env.example .env          # Linux/macOS: cp .env.example .env
# впиши BOT_TOKEN в .env

python bot.py
```

Бот запустится в режиме long polling и напишет в лог `бот запущен`.
В Telegram: `/start` → отправь видео.

### Если ffmpeg не установлен

Раскомментируй в `requirements.txt` строку `imageio-ffmpeg` и переустанови
зависимости — бот возьмёт бинарник из пакета. `ffprobe` в комплект не входит,
поэтому бот автоматически переключится на разбор вывода `ffmpeg -i` —
функциональность та же.

## Настройки (`.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather, обязателен |
| `TELEGRAM_API_SERVER` | пусто | адрес локального Bot API server (снимает лимит 20 МБ) |
| `TELEGRAM_API_IP` | пусто | прямой IP для `api.telegram.org` (обход блокировки) |
| `MAX_INPUT_MB` | `20` | максимальный входной файл, МБ |
| `NOTE_MAX_MB` | `5` | целевой размер кружка, МБ |
| `FALLBACK_NOTE_MB` | `1` | на этот размер пережмёт, если Telegram откажет |
| `MAX_SIDE` | `640` | сторона квадрата, px |
| `MAX_DURATION` | `60` | максимальная длина, секунд |
| `FFMPEG_PRESET` | `fast` | пресет x264 (`veryfast` — быстрее, `medium` — качественнее) |
| `MAX_CONCURRENT` | `2` | одновременных конвертаций |
| `DOWNLOAD_TIMEOUT` | `600` | таймаут скачивания, секунд |
| `CONVERT_TIMEOUT` | `600` | таймаут конвертации, секунд |
| `LOG_LEVEL` | `INFO` | уровень логирования |

## Как это работает

1. Бот находит видео в сообщении или в сообщении, на которое ответили.
2. Скачивает файл во временную папку (через Bot API — лимит 20 МБ).
3. `ffprobe` достаёт длительность, разрешение и наличие звука.
4. Считает битрейт: `(целевой_размер × 8 × 0.94) / длительность − аудио`.
5. Кодирует **два прохода** x264 (ABR + VBV), фильтр:
   `crop` до квадрата → `scale` до 640 px → чётные стороны → 30 fps → `yuv420p`.
6. Если файл всё равно больше цели — повторяет с меньшим битрейтом
   (до 4 попыток), затем пытается отправить.
7. Если Telegram отвечает ошибкой на `sendVideoNote` — пережимает до
   `FALLBACK_NOTE_MB` и пробует снова.

Аудио: AAC, моно, 44.1 кГц, 48–64 kbps (только если в исходнике есть звук).

## Ограничения

- **20 МБ на скачивание** — ограничение облачного Bot API, не бота.
  Для больших файлов нужен локальный Bot API server:
  `TELEGRAM_API_SERVER=http://localhost:8081` и `MAX_INPUT_MB=2000`.
- В документации Bot API у кружка указан лимит **1 МБ**, хотя на практике
  проходят и файлы крупнее. По умолчанию бот целится в 5 МБ и автоматически
  откатывается к 1 МБ, если Telegram откажет. Хочешь гарантию — поставь
  `NOTE_MAX_MB=1`.
- Кружок — всегда квадрат: широкое видео обрезается по центру, а не
  вписывается с полями.
- Конвертация требует CPU: 60-секундный ролик на `fast` — обычно 10–30 с.

## Если что-то не так

- **`Cannot connect to host api.telegram.org`** — адрес Telegram заблокирован
  провайдером (DNS отдаёт недоступный IP). Бот умеет ходить на конкретный адрес:

  ```bash
  curl.exe -sS --resolve api.telegram.org:443:149.154.167.220 https://api.telegram.org/
  ```

  Если в ответ пришёл `302` — впиши в `.env`:

  ```env
  TELEGRAM_API_IP=149.154.167.220
  ```

  Заданный IP используется первым, а обычный DNS остаётся запасным вариантом.
  Альтернатива — VPN или системный прокси.
- **`ffmpeg не найден`** — установи ffmpeg и добавь `bin` в `PATH`,
  либо поставь `imageio-ffmpeg`.
- **`BOT_TOKEN не задан`** — скопируй `.env.example` в `.env`.
- **`Файл слишком большой`** — сожми видео или подними локальный Bot API server.
- **Кружок не отправился** — смотри лог: там будет ответ Telegram,
  бот уже попробует ужать файл до 1 МБ.
